# Hongzhan Printing Website

一个专业的纸质包装和印刷厂网站。

## 项目描述

Hongzhan Printing 是一个位于中国东莞市的纸质包装和印刷生产商。本网站展示了我们的主要产品和服务。

## 功能特性

- 响应式网页设计
- 产品展示列表
- 公司介绍
- 在线咨询表单
- 联系信息

## 主要产品

1. **Custom Color Gift Box** - 艺术纸、铜版纸包装盒
2. **Product Catalog & Brochure** - 高光泽全彩宣传册印刷
3. **User Instruction Book** - 多语言产品使用手册
4. **Hang Tag & Paper Card** - 服装标签、包装卡片定制
